# 🏄‍♂️ Surfboard — Premium Interactive Landing Page

## 💼 Project Description

[![Кликните, чтобы открыть сайт](./preview.jpg)](https://euhenihreben.github.io/Surfboard/)

- **Project:** Surfboard — Premium Interactive One-Page Landing Page for a Surfboard Brand.
- **Objective:** End-to-end development of a high-converting, fully responsive landing page featuring seamless scrolling, custom media players, and interactive map integrations.
- **Tech Stack:** HTML5, CSS3 / SCSS (BEM methodology, modular structure), JavaScript (ES6+), jQuery, Swiper.js, Yandex Maps API.

### 🚀 Key Deliverables & Features:

- **One-Page Scroll Navigation:** Engineered a flawless screen-by-screen scrolling system with touch-gesture optimization for mobile devices.
- **Modular Code Architecture:** Built a highly maintainable codebase (SCSS styles and JS logic are split into independent components: `video.js`, `order.js`, `map.js`).
- **Interactive Elements:** Developed a dynamic product catalog and a smooth testimonial slider powered by Swiper.js.
- **Custom Media & Maps:** Implemented a custom-styled HTML5 video player and integrated an interactive map via Yandex Maps API.
- **Smart Checkout Form:** Integrated a multi-input checkout and delivery form with client-side data validation.
- **Pixel-Perfect & Responsive:** Delivered 100% responsive, cross-browser layout optimized for all modern device sizes.

## 🛠️ Quick Start

To run this project locally, follow these simple steps:

1. **Clone the repository:**

   ```bash
   git clone https://github.com/EuheniHreben/Surfboard.git
   ```

2. **Launch the website:**
   Open the `index.html` file directly in your browser, or use a local development server like the _Live Server_ extension in VS Code.
